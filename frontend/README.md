# Frontend Service

React + Vite frontend supporting basic Document intelligence routing via chat.

### Environment & Setup
1. Define `VITE_DOCUMENT_SERVICE_URL` and `VITE_CHAT_SERVICE_URL` or fallback to localhost port 8001 / 8002 defaults natively.
2. `npm install`.
3. `npm run dev`.

### Features
- Dash showing realtime doc processing mapping react-query poll.
- SSE streams visually append into components mimicking smooth chat transitions.
